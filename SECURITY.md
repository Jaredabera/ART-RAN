# Security and Responsible Use

ART-RAN is a research framework for studying adversarial vulnerabilities in agentic O-RAN control pipelines. Use it only on systems, datasets, simulators, emulators, testbeds, or networks for which you have authorization.

Please do not use this repository to disrupt operational telecommunications networks or to bypass access controls.

For security-sensitive implementation issues, avoid publishing credentials, tokens, private infrastructure addresses, or sensitive testbed configuration in public issues. Contact the maintainers privately when appropriate.
